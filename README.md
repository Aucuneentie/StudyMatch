# StudyMatch
StudyMatch — мобильное приложение для школьников, которое помогает не пропустить олимпиады и экзамены. Персональная подборка мероприятий по профилю, умные напоминания о дедлайнах, материалы для подготовки и подбор подходящих вузов.
